## 1. 数据持久化（P0）—— 让线上新数据长期保留

**现状**：Render 免费版磁盘是临时的，且启动命令带 `npm run seed`（每次启动重灌演示数据）。
所以线上数据**一重启/重新部署就重置**。要正式用，必须做持久化。

### 方案 A：Render 持久磁盘（改动小，推荐）
> 需要 Render **付费实例**（约 $7/月起；免费版不支持持久磁盘）。

- [ ] Render → 你的服务 → **Settings → Disks → Add Disk**：挂载路径填绝对路径（如 `/var/data`），大小 1 GB 即可。
- [ ] 让数据库写到这块盘——把 `src/db/index.js` 第 5 行改成可配置：
  ```js
  const DATA_DIR = process.env.DATA_DIR || path.join(__dirname, '..', '..', 'data');
  ```
  并在 Render 环境变量加 `DATA_DIR=/var/data`（与挂载路径一致）。
- [ ] 去掉"每次启动重灌"——`render.yaml` 的 `startCommand` 从
  `npm run seed && npm start` 改为只 **`npm start`**。
- [ ] 首次上线后**手动种一次**基础数据（`npm run seed` 或在平台跑一次），或直接让 admin 从零建账号。之后数据长期保留。
- [ ] 定期备份这块盘上的 `crm.db`（见第 4 节）。

### 方案 B：外部数据库（更稳，改动大）
- [ ] 换成托管 Postgres/MySQL（支持多实例、更稳）。需要把数据层从 `node:sqlite` 改写到对应驱动，工作量较大。演示阶段不必，规模上来再考虑。
